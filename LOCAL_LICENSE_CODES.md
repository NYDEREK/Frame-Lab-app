# Frame Lab local activation codes

These reusable codes are validated only inside the installed application. A code can be used on any number of separate installations, but the same installation records its hash and will not accept that code again after it expires.

| Tier | Code | Access |
| --- | --- | --- |
| Personal Year | `3184-1815-3029` | Personal Creator access for one year |
| Commercial Year | `6752-1850-6811` | Commercial Creator access for one year |
| Lifetime Personal | `1847-2294-6103` | Lifetime personal Creator access |
| Lifetime Commercial | `5729-6041-8832` | Lifetime commercial Creator access |
| Supporter | `8104-7702-1099` | Support contribution; does not unlock Creator |
| Ultra Support | `9364-1558-2706` | Lifetime top-tier Creator access |

Activation history, the current license and all projects are stored in the application data directory on the user's computer. No account, email address or network connection is required.
